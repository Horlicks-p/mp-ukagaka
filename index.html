Volumen Primum

MP Ukagaka

AI 対応 WordPress 伺かプラグイン

WordPress サイトに伺かキャラクターを住まわせるプラグイン。
記事を読んで感想をこぼし、訪問者と言葉を交わし、
夜には眠り、贈り物には少しだけ表情を変える。

最新版をダウンロード ライブデモ GitHub

· Capitulum I ·

主な機能

ビルドもフレームワークも不要。
WordPress プラグインとして入れるだけで、キャラクターが話し始めます。

Colloquium · 語る

AI ページ感知

閲覧中の記事を読み取り、選んだ LLM がキャラクターの口調で感想を生成。確率と対象ページを設定できます。

対話モード

SSE ストリーミングによる多ターン会話。履歴はブラウザに保存され、チェックサムでサーバー側と整合性を確認します。

自発的なおしゃべり

静的セリフ、または LLM が時間帯・季節・訪問状況からその場で生成するセリフ。来訪の初回には AI の挨拶も。

記憶

管理者は /remember で会話から事実を抽出し、キャラクターに覚えさせられます。次の会話から反映されます。

Interactio · 触れる

贈り物・食べ物

対話モードの 🎁 から品物を渡すと、品物と添えた言葉の両方にキャラクターが反応します。品目は items.json で定義。

睡眠と目覚め

深夜は眠り、朝は寝坊し、昼には昼寝も。話しかけると目覚めのアニメーションと一言のあと、また話し始めます。

タッチと装飾品

頭や手などのタッチゾーン、周囲の装飾品をクリックすると、それぞれに応じた反応を返します。

Canvas アニメーション

1 枚絵から連番フレームまで。フォルダ内の画像を自然順に再生し、絵文字・思考吹き出しも重ねられます。

Opera · 働く

Abilities

WordPress Abilities API と連携し、人気記事の確認・Bot 統計・IP ブロックなどを会話の中で実行します。

AI 日記

1 日 1 回、設定した確率でキャラクターが日記を書いて投稿。日記用には別の AI プロバイダーを選べます。

天気とカレンダー

Open-Meteo（キー不要）の天気、calendar.json の季節・祝日、管理人の誕生日を会話に織り込みます。

Bot 防護とセキュリティ

Bot 防護を内蔵。API キーは AES-256-GCM で暗号化保存、匿名訪問者の AI 呼び出しはセッショントークンで保護。

Fabrica · 作る

キャラクター作成

manifest.json と画像、personality.md などをまとめた ZIP を管理画面からアップロードして追加できます。

多言語対応

管理画面とログは英語・繁体字中国語・日本語に対応。AI の応答言語はキャラクターごと、または全体で設定できます。

拡張しやすい構造

REST コントローラ、AI プロバイダー Factory、フィルター・アクション、外部 .txt / .json ダイアログ。

· Capitulum II ·

対応する AI プロバイダー

管理画面の「LLM 設定」でいつでも切り替えられます。
API キーは保存時に暗号化され、平文では残りません。

Ollama

無料 ・ ローカル

手元または自前のリモートサーバーで実行。Qwen3 などの思考モデルにも対応し、API 利用料はかかりません。

Gemini

有料 API

高速・低コスト。ストリーミングとツール呼び出しに対応します。

既定 gemini-2.5-flash

OpenAI

有料 API

mini 系モデルが生成品質と API コストのバランスに優れ、普段使いにおすすめです。

既定 gpt-4.1-mini

Claude

有料 API

表現力が豊かで、ニュアンスのあるキャラクター対話に向いています。

既定 claude-sonnet-4-6

日記は別のプロバイダー・キーで動かせます。会話は Ollama、日記はクラウド、といった使い分けも可能です。

· Capitulum IV ·

クイックスタート

ZIP をアップロードして有効化するだけ。
以降の更新は WordPress の管理画面に通知されます。

I

ダウンロード

最新リリースの mp-ukagaka.zip を入手します。GitHub の「Source code」ではなく、こちらを使ってください。

II

インストール

プラグイン → 新規追加 → プラグインのアップロード で ZIP を選び、有効化します。

III

基本設定

設定 → MP Ukagaka の一般設定で表示を確認。フリーレンは内蔵セリフですぐに話し始めます。

IV

AI を有効化 （任意）

LLM 設定でプロバイダーとキーを登録し、ページ感知や対話モードを有効にします。

要件：WordPress 5.0 以上 ・ PHP 7.4 以上。AI 機能には OpenSSL 拡張と wp-config.php の AUTH_KEY が必要です。
