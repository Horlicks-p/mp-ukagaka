Gemini・OpenAI・Claude・Ollama を通じて、
記事内容に応じた AI 会話やインタラクティブな対話を実現します。

· CAPITULUM I ·

主な機能

ビルドステップやフレームワークは不要。
WordPress プラグインとして、すぐに使い始められます。

AI ページ感知

記事内容を読み込み、選択した LLM プロバイダーが文脈に合わせたコメントを自動生成します。

インタラクティブ対話モード

SSE ストリーミングによるリアルタイム多ターン会話。タイプライター効果と会話履歴の保持に対応。

Canvas アニメーション

単一画像から複数フレームのスプライトまで対応。キャラクターごとに表示を細かくカスタマイズできます。

API キー暗号化

API キーは WordPress の salt から導出した AES-256-CBC で暗号化保存。平文でデータベースに残りません。

多言語対応

英語・繁体字中国語・日本語の翻訳を同梱。gettext ベースの i18n / l10n に完全対応しています。

モジュラー構造

オブジェクト指向 PHP・REST API コントローラ・プロバイダー Factory、そして拡張用の 40 以上のフック。

カレンダー & イベント

calendar.json による季節・祝祭日対応。管理人の誕生日にも自動でリアクションします。

セキュリティ重視

nonce による CSRF 検証、wp_kses での XSS 防止、Turnstile・Akismet との連携に対応。

外部ダイアログファイル

外部の .txt や .json からダイアログを読み込み可能。フリーレンの内蔵セリフも同梱。

· CAPITULUM II ·

対応する AI プロバイダー

4 つの主要な LLM プロバイダーをサポート。
管理画面からいつでも切り替え可能で、API キーは保存時に自動暗号化されます。

Ollama
無料 ・ ローカル

ローカルまたは自前のリモートサーバーで実行。API 利用料は一切かかりません。

Gemini
有料 API

Google Gemini 2.5 Flash 推奨。高速・低コストで、SSE ストリーミングにも対応。

OpenAI
有料 API

GPT-4o mini が、生成品質と API コストのバランス面で最もおすすめです。

Claude
有料 API

Anthropic Claude — 表現力豊かで、ニュアンスのあるキャラクター対話に向いています。

· CAPITULUM IV ·

クイックスタート

ビルドステップ不要。
プラグインフォルダに配置して有効化するだけで使い始められます。

I

ダウンロード

プラグインを wp-content/plugins/mp-ukagaka/ に複製または展開します。

II

有効化

WordPress 管理画面 → プラグイン から MP Ukagaka を有効化します。

III

基本設定

設定 → MP Ukagaka でデフォルトキャラクター・表示位置などを設定します。

IV

AI キーを登録

Gemini・OpenAI・Claude・Ollama いずれかの API キーを登録すれば、AI 会話が有効になります。（任意）
