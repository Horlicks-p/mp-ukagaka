Features

Everything in one plugin

A complete ukagaka experience for WordPress — no build step or JavaScript framework required.

🤖

Page-Aware AI Dialogue

Reads your article content and generates contextually relevant responses using your chosen LLM provider.

💬

Interactive Chat Mode

Real-time multi-turn conversations via SSE streaming — with a typewriter effect and conversation history.

🎨

Canvas Animation

Smooth character animations with single-image or multi-frame sprite support. Fully customizable.

🔑

API Key Encryption

All API keys are stored with AES-256-CBC encryption derived from WordPress salts. Never stored in plaintext.

🌐

Multi-Language

Built-in translations for English, Traditional Chinese (zh-TW), and Japanese. Full i18n/l10n support.

🧩

Modular Architecture

Clean PHP OO design with REST API controllers, provider factory pattern, and 40+ hooks for extensibility.

📅

Calendar & Events

Character reacts to seasons and holidays via calendar.json — including your birthday.

🛡️

Security-First

CSRF nonce verification, XSS prevention via wp_kses, Turnstile and Akismet integrations.

📖

Dialog Files

Load dialogues from external .txt or .json files. Built-in Frieren personality included.

AI Integration

Getting Started

Up and running in minutes

No build step required — drop into your plugins folder and activate.

01

Download

Clone or download into wp-content/plugins/mp-ukagaka/

02

Activate

Go to WordPress Admin → Plugins and activate MP Ukagaka.

03

Configure

Visit Settings → MP Ukagaka to choose a character and display settings.

04

Add AI Key

Enter a Gemini, OpenAI, or Claude API key to enable context-aware dialogue. (Optional)
