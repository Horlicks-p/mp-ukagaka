MP Ukagaka

AI-Powered WordPress Companion

Bring an interactive ukagaka (伺か) character to your WordPress site. Reads page content, chats with visitors, and responds with personality — powered by your choice of AI model.

✦ Live Demo ⬡ GitHub ↓ Download ZIP
Core Features

Everything in one plugin

A complete ukagaka experience for WordPress — no JavaScript framework required.

🤖

Page-Aware AI Dialogue

The character reads your article content and generates contextually relevant responses using your chosen LLM provider.

💬

Interactive Chat Mode

Real-time multi-turn conversations with visitors via SSE streaming — with a typewriter effect and conversation history.

🎨

Canvas Animation

Smooth character animations with single-image or multi-frame sprite support. Fully customizable via settings.

🔑

API Key Encryption

All API keys are stored with AES-256-CBC encryption derived from WordPress salts. Never stored in plaintext.

🌐

Multi-Language

Built-in translations for English, Traditional Chinese (zh-TW), and Japanese. Full i18n/l10n support.

🧩

Modular Architecture

Clean PHP OO design with REST API controllers, provider factory pattern, and 40+ hooks for extensibility.

📅

Calendar & Events

Character reacts to real-world events, seasons, and holidays via calendar.json — including your birthday.

🛡️

Security-First

CSRF nonce verification, XSS prevention via wp_kses, Turnstile and Akismet integrations.

📖

Dialog Files

Load dialogues from external .txt or .json files. Built-in Frieren personality and memory included.

Getting Started

Up and running in minutes

No build step required — drop into your plugins folder and activate.

Download

Clone or download this repo into wp-content/plugins/mp-ukagaka/

Activate

Go to WordPress Admin → Plugins and activate MP Ukagaka.

Configure

Visit Settings → MP Ukagaka to choose a character and set your AI provider.

(Optional) Add AI Key

Enter a Gemini, OpenAI, or Claude API key to enable context-aware dialogue generation.
