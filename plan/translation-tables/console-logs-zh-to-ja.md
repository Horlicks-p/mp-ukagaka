## Inventory Bootstrap

Run these from the repo root to generate the initial call-site list before
translation review:

```powershell
rg -n --multiline 'console\.(log|warn|error|info)\s*\([^)]*[一-鿿]' js/ ghost/Frieren/
rg -n 'mpuLogger\.(log|warn|error|info)\s*\([^)]*[一-鿿]' js/ ghost/Frieren/
```

After collecting the raw list, normalize each row manually:

- Exclude `js/dist/**`; dist files are generated by build.
- Mark production-visible direct `console.error` / `console.warn` rows as
  `logs`.
- Mark existing debug-gated `mpuLogger.log` / `warn` / `info` rows as
  `logsDebug`.
- Use `logs` for `mpuLogger.error` because `error()` is always output.
- For `ghost/Frieren/**`, use a `frieren` key prefix.
